Privacy Policy

GA4 Name Changer

Effective date: June 2026  ·  Chrome Extension

This extension does not collect, transmit, or share any personal data. Ever.

What data does this extension access?

GA4 Name Changer reads the text content of the Google Analytics interface (analytics.google.com) to locate and replace property slugs with your custom names. This processing happens entirely within your browser — no data is extracted or sent anywhere.

What data does this extension store?

The only data stored is the slug-to-name mapping you create in the Settings page. This is stored using Chrome's built-in chrome.storage.sync API, which means:

  • Your mappings are saved locally in your Chrome browser profile.
  • If you are signed into Chrome, Google may sync this data to your other devices through your Google account, subject to Google's own privacy policy.
  • This extension never reads, copies, or transmits your mappings to any server operated by this extension's developer.

Does this extension send any data to external servers?

No. The extension has no backend, no analytics, no tracking, and makes zero network requests. It operates entirely offline after installation.

Permissions used

  • storage — to save your slug-to-name mappings.
  • Host permission for analytics.google.com — to inject the content script that performs text replacement on the GA4 interface.

No other permissions are requested.

Contact

If you have questions about this privacy policy, please open an issue on the extension's support page in the Chrome Web Store.

GA4 Name Changer is an independent tool and is not affiliated with or endorsed by Google.
