Give your GA4 properties real names

Google shares Chrome Web Store analytics under a 32-character extension ID, and labels every account identically. This extension swaps those identifiers for names you choose, live inside Google Analytics.

Optional

Let it name them for you

That 32-character slug is your extension's ID. Turn this on and any of those extensions installed in this Chrome profile are named automatically, instantly and entirely offline. You review every suggestion before saving.

  • Names are read locally with Chrome's management API. Nothing is sent anywhere, and the extension still makes no network requests at all.
  • Chrome asks your permission first, and turning this back off revokes it.
  • Only names are read. Nothing is installed, enabled, disabled or changed.
  • An extension that is not installed here cannot be named this way. Those rows get a link that opens the public Chrome Web Store listing so you can read the name.
