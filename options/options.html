Google Analytics (GA4) Name Changer for Chrome Extension Developers

Map GA4 account numbers and property slugs to readable names

On by default. Names are worked out from the Google Analytics page you are already looking at and applied straight away, with no save and no network request. Anything you type below overrides them.

Asks Chrome for the management permission, then names any slug matching an extension installed in this profile. Only names are read. Turning this off gives the permission back.

How are these names worked out?

Your GA4 property slug is your extension's Chrome Web Store ID. Three sources turn it into a name, tried in order. Nothing is ever sent anywhere.

  1. Your own GA4 reports. Google's report of your most-viewed pages lists your store listing, and the store titles it <Extension Name> – Chrome Web Store. The name is split off the end of that title, so it is read straight from the page you are already viewing. Works in any language, and for extensions you do not have installed.
  2. Your installed extensions. Optional. If you grant the management permission, any slug matching an extension installed in this Chrome profile is named from Chrome directly.
  3. The store listing link. Anything the first two cannot name shows a link on its row that opens its public listing, so you can read the name and type it.

Names appear a few seconds after you open a property, once Google Analytics has finished loading the report they are read from. Switching property inside Google Analytics takes a moment longer, because its own reports lag the switch.

An account is named after the extension it holds, shortened. An account holding more than one has no single right name, so it gets a draft made from all of them — Amazon MyOrders + Flip Rotate — with any extension not yet named counted as + 1 more. Every draft is yours to rewrite. Names the extension worked out are marked auto; edit any of them and press Save to make it permanently yours.

Optional

Let it name them for you

That 32-character slug is your extension's ID. Turn this on and any of those extensions installed in this Chrome profile are named automatically, instantly and entirely offline. You review every suggestion before saving.

  • Names are read locally with Chrome's management API. Nothing is sent anywhere, and the extension still makes no network requests at all.
  • Chrome asks your permission first, and turning this back off revokes it.
  • Only names are read. Nothing is installed, enabled, disabled or changed.
  • An extension that is not installed here cannot be named this way. Those rows get a link that opens the public Chrome Web Store listing so you can read the name.
